# Inventory Management System

A premium, modern Inventory and Sales Management System built with Flutter.

## ✨ Project Overview
This application provides a comprehensive solution for managing inventory, tracking sales performance, and generating detailed business analytics. It features a stunning, high-performance UI designed with modern aesthetics and professional color palettes.

## 🎨 Design Overhaul
The project has recently undergone a significant visual transformation:
- **Premium Green Theme**: Replaced the legacy purple color scheme with a professional Dark Green (`#1B5E20`) theme, providing a more modern and business-centric feel.
- **Modern Card-based UI**: All list views (Reports, Products, Analytics) have been updated to use a consistent, high-end card design with subtle shadows, rounded corners (24px), and intuitive iconography.
- **Micro-interactions**: Enhanced user experience with smooth transitions and responsive interactive elements.

## 🚀 Key Features
- **Dashboard Analytics**: Real-time visualization of daily performance using dynamic bar charts.
- **Inventory Management**: Full CRUD operations for products with stock level monitoring and barcode tracking.
- **Comprehensive Reporting**:
  - Daily & Range Sales Reports
  - Best Selling Products Analysis
  - Profitability Tracking
  - Low Stock Alerts
  - Item Analysis (Earnings vs. Expenses)
- **PDF Export**: Generate professional PDF reports for all analytics data directly from the app.
- **Receipts History**: Searchable history of all transactions and invoices.

## 🛠 Tech Stack
- **Framework**: [Flutter](https://flutter.dev)
- **State Management**: [Provider](https://pub.dev/packages/provider) & [GetX](https://pub.dev/packages/get)
- **Iconography**: [Iconsax](https://iconsax.io/)
- **Database**: [SQLite](https://pub.dev/packages/sqflite) (local storage)
- **PDF Generation**: [pdf](https://pub.dev/packages/pdf)

## 🏁 Getting Started

### Prerequisites
- Flutter SDK (Latest Stable)
- Android Studio / VS Code
- Dart SDK

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Isaac-onah/Inventorymgtsys.git
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
